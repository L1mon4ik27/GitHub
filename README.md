# Hello World

Мой первый проект на HTML. Отображает приветствие в браузере.

## О проекте

Простая веб-страница, которая показывает надпись «Hello World!».
Стили вынесены в отдельный CSS-файл, поэтому внешний вид легко изменить.

## Структура проекта

```text
.
├── index.html
├── CSS/
│   └── style.css
└── README.md
```

- `index.html` — основная страница.
- `CSS/style.css` — стили страницы.
- `README.md` — описание проекта.

## Как запустить

1. Склонируйте репозиторий или скачайте все файлы, сохранив структуру папок.
2. Откройте `index.html` в любом современном браузере: Chrome, Firefox, Edge.
3. Вы увидите надпись «Hello World!» по центру по горизонтали.
