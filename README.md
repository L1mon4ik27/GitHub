# Hello World

Мой первый проект на HTML. Отображает приветствие в браузере.

## Как запустить

1. Скачайте файл `index.html`.
2. Откройте его в любом браузере (Chrome, Firefox, Edge).
3. Вы увидите надпись «Hello World!» по центру экрана.
4. Стили можно менять в `style.css`.

## Технологии

- HTML5
- CSS
