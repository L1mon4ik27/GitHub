# Hello World

Мой первый проект на HTML. Отображает приветствие в браузере.

## О проекте

Простая веб-страница с заголовком «Hello World!».
С помощью поля ввода и кнопки можно изменить текст заголовка.
Стили вынесены в отдельный CSS-файл, логика — в отдельный JS-файл.

## Структура проекта

```text
.
├── index.html
├── CSS/
│   └── style.css
├── JS/
│   └── main.js
└── README.md
```

- `index.html` — основная страница.
- `CSS/style.css` — стили страницы.
- `JS/main.js` — логика смены заголовка.
- `README.md` — описание проекта.

## Как запустить

1. Склонируйте репозиторий или скачайте все файлы, сохранив структуру папок.
2. Откройте `index.html` в любом современном браузере: Chrome, Firefox, Edge.
3. Введите новый текст в поле и нажмите кнопку «Изменить».
4. Если поле пустое, заголовок вернётся к «Hello World!».
