# Мой первый проект

Это мой самый первый репозиторий на GitHub. Учебный проект, в котором я пробую разные вещи на HTML, CSS и JavaScript.

## О проекте

Проект начинался как простая страница «Hello World», но постепенно превратился в песочницу для экспериментов. Сейчас в нём есть:

- Изменение заголовка через поле ввода и кнопку.
- Сохранение текста заголовка в `localStorage` — заголовок не сбрасывается после перезагрузки.
- Пасхалка: если ввести `SECRET_1`, заголовок покажет случайную мемную фразу.
- Многостраничная структура с общей шапкой и подвалом на CSS Grid.

## Структура проекта

```text
.
├── index.html
├── header-page.html
├── CSS/
│   └── style.css
├── JS/
│   └── main.js
└── README.md
```

- `index.html` — главная страница (пока с заглушкой).
- `header-page.html` — страница с интерактивным заголовком и пасхалкой.
- `CSS/style.css` — общие стили для всех страниц.
- `JS/main.js` — логика смены заголовка.
- `README.md` — описание проекта.

## Как запустить

1. Склонируйте репозиторий или скачайте все файлы, сохранив структуру папок.
2. Откройте `index.html` в любом современном браузере: Chrome, Firefox, Edge.
3. Перейдите на страницу «Заголовок», чтобы проверить функционал.

## Пасхалка

Введите `SECRET_1` в поле ввода и нажмите «Изменить» — увидите одну из случайных мемных фраз.
